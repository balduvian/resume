# Resume

[Resume](./out/resume.pdf)

## Installation

This project is built on Windows.

This project uses [TeX Live](https://www.tug.org/texlive).

This project uses [InkScape](https://inkscape.org/release/inkscape-1.4.2/windows/64-bit/msi/dl/). After installation, you must put `inkscape` on `PATH`.

## Building

Run `.\build.ps1` in Powershell.

The built PDF is found in [`/out/resume.pdf`](./out/resume.pdf).

## VSCode Latex Extension

To develop, use the [LaTeX Workshop](https://marketplace.visualstudio.com/items?itemName=James-Yu.latex-workshop) VSCode extension.

[`.vscode/settings.json`](.vscode/settings.json) contains the `latex-workshop` settings required to build on file save.
